2. DX-66470 Changes on 3.3.6 Fork

Goal: Introduce SharedKeySigner interface so Dremio can plug in a custom signer class (e.g., for credential delegation) instead of being locked to SharedKeyCredentials.
CHANGED — Entry Point
AzureBlobFileSystemStore
creds = new SharedKeyCredentials(accountName, key) signer = abfsConfiguration.createSharedKeySigner(accountName)
client = new AbfsClient(url, creds, ...tokenProvider, ctx) client = new AbfsClient(url, signer, conf, ctx) // SharedKey auth
// OAuth and SAS paths unchanged (pass null signer)
CHANGED — AbfsConfiguration
AbfsConfiguration
+ FS_AZURE_SHARED_KEY_SIGNER = "fs.azure.shared.key.signer"
+ getSharedKeySigner() → SharedKeySigner
{

SharedKeyCredentials.class, SharedKeySigner.class)

if (signerClass == SharedKeyCredentials.class)
return new SharedKeyCredentials(name, key) // default
else
return ReflectionUtils.newInstance(signerClass, rawConfig) // custom
}

3. Upstream 3.4.3 — Refactored Architecture

Key change: AbfsClient is now abstract with two subclasses. A new AbfsClientHandler mediates between them. signRequest() now takes AbfsHttpOperation instead of HttpURLConnection.
